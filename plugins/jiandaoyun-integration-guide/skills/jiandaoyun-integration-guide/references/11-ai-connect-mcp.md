1. 简介

1.1 功能简介

AI 连接 是指生成成员个人身份的 MCP 服务授权链接，通过链接可将简道云无缝嵌入到 AI Agent、代码编辑器、命令行工具等第三方平台中，支持通过第三方平台直接查看简道云中的待办事项、查询数据、获取用户消息、向简道云表单中新增数据等操作，进一步实现跨平台自动化与数据协同。

AI 连接与 OpenAPI 的区别：

1）AI 连接为个人服务权限，并且将对应接口封装成了工具类，即配置完 AI 连接后，用户就完成了身份授权，可以直接使用对应工具。

2）AI 连接中封装的工具对于 AI Agent 调用的场景会比直接调用 API 更友好。

1.2 使用场景

适用于通过 AI 助手操作简道云的各类场景中。如：

快速获取简道云待办和数据：通过 AI 连接中的 MCP 服务查询当前用户待办任务及关联表单数据，辅助智能决策；
聚合个人工作信息：将待办任务、可访问应用以及成员信息集中展示在自定义面板中，实现工作状态一站式管理。
向简道云表单中新增数据：通过 AI 连接中的 MCP 服务向简道云表单中新增数据，减少跨系统操作，提高协作效率。

2. 操作步骤

2.1 开启 AI 连接

在「账户中心 >> 管理后台 >> 企业设置 >> 企业安全」处，开启 AI 连接。

2.2 新建 AI 连接

进入「开放平台 >> 开发者工具 >> AI 连接 >> AI 连接」中，点击「创建 AI 连接」，进行如下所示设置：

AI 连接名称：企业可根据业务需求自定义 AI 连接名称；
授权有效期：系统支持 7 天、30 天、60 天、90 天、无期限和自定义天数；
可用能力：企业可根据业务需求自定义勾选不同的能力，系统支持查看待办事项、查询应用和表单中的数据、获取用户信息和新增数据 4 项能力。
全部设置完成后点击「创建」，即可创建成功。

注：

1）AI 连接对简道云的操作权限和授权者保持一致，企业成员仅能操作自己有权限的表单和数据。

2）企业成员创建 AI 连接时，「新增数据」为需审核能力，成员需向管理员提交申请并审核通过后，方可使用。

3. AI 连接管理

3.1 编辑 AI 连接

若需对 AI 连接名称、授权有效期和可用能力进行修改，点击 AI 连接卡片右上角的「编辑」按钮，即可修改。

3.2 删除 AI 连接

若确认当前企业不再需要 AI 连接，点击 AI 连接右上角的删除按钮，进行删除二次确认后，即可删除成功。

3.3 查看/导出调用日志

管理员进入「开发者工具 >> AI 连接」中，点击「调用日志」，即可查看/导出相关日志。系统支持通过以下维度进行筛选查看/导出：

操作人
操作类型
操作时间

4. 支持调用的工具

MCP 服务目前支持调用如下工具：

member_data_create：创建一条表单数据
member_app_entry_list：获取应用下的表单列表(个人视角)
member_app_entry_widget_list：获取表单字段列表(个人视角)
member_app_list：获取当前成员可访问的应用列表
member_data_get：查询单条数据详情(个人视角)
member_data_list：查询多条数据(个人视角)
member_managed_data_get： 查询单条数据详情（同数据管理页面）
member_managed_data_list： 查询多条数据（同数据管理页面）
member_user_info： 获取当前登录成员的信息
member_workflow_task_list： 获取个人工作流待办列表
get_tool_schema：获取指定工具的出参 JSON Schema。用于在 agent client 丢失返回值结构缓存时按需恢复；入参 schema 已通过 tools/list 提供，此处不重复返回。
get_tool_help：获取指定工具的 Markdown 格式深度使用帮助。当前支持如下工具:
member_data_list
member_data_create
member_managed_data_list
 member_workflow_task_list
5. 注意事项

1）MCP 的频率为 3 次/秒。

2）通过 MCP 写入的数据，在数据日志上会看到 MCP 写入标记。

3）MCP 写入有如下所示限制：

暂不支持写入选择数据、关联数据、图片和附件字段；
不会触发数据联动、公式计算、前端事件、数据校验等；
不具备显隐控制能力，可以写入不可见字段。
4）若需通过 MCP 写入发起流程、触发智能助手需在创建数据时给出明确的指令，否则将默认不会发起流程和触发智能助手。

5）在与 MCP 交流过程中，若遇到以下问题，可以在对话中添加一个提示词：调用简道云MCP之前，优先调用 get_tool_help 这个工具，再执行具体的业务查询（如查询待办、查询表单数据）

无法精准识别参数名；
分页标记使用错误
参数大小写无法区分；
MCP 查询分页报错；
filter 过滤问题。

## 可用能力审核

- 官方文档：https://hc.jiandaoyun.com/open/26603

1. 简介

1.1 功能简介

在企业数据平台中，企业成员创建 AI 连接时，需向管理员提交「新增数据」能力申请，管理员通过申请后，成员才可通过第三方平台在简道云表单中进行新增数据等操作。为企业成员提供标准化申请渠道，确保企业数据安全可控，满足业务对实时性、合规性的要求，进一步提升管理效率。

1.2 应用场景

适用于企业业务复杂，需要管理员进行数据写入统一管理的场景中。

1.3 预期效果

以拒绝成员能力申请为例，效果如下所示：

2. 操作步骤

2.1 申请可用能力

企业成员创建 AI 连接时，勾选「新增数据」能力并填写申请理由后，点击「创建并提交申请」。

2.2 审批可用能力

1）企业管理员收到能力申请后，可在「开放平台 >> AI 连接 >> 审核列表」中，查看申请并进行审批。

2）在能力开通申请页中，点击「同意」按钮，成员能力开通申请即可通过。

3）管理员也可根据企业需求，拒绝成员能力开通申请。点击「拒绝」按钮并填写拒绝理由后，提交即可。

2.3 批量操作

若有多个企业成员申请新增数据能力，企业管理员可在「审核列表」中勾选多个申请，进行批量同意或者批量拒绝。

2.4 搜索能力申请

在「审核列表」页面中，支持企业管理员通过如下数据快速查找能力申请：

申请人
所属 AI 连接名称
能力类型

2.5 筛选能力申请

管理员也可根据以下状态，快速筛选能力申请：

待审批
已通过
已拒绝
已失效

3. 注意事项

1）仅企业成员创建 AI 连接时的「新增数据」能力需要申请，系统管理员创建时无需申请。

2）若审核不通过或企业成员没有申请能力，则无法调用新增数据能力。
