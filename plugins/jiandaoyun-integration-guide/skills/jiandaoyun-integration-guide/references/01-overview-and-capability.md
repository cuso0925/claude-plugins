## 简道云集成/对接能力说明

- 官方文档：https://hc.jiandaoyun.com/doc/20944

1. 平台集成

支持将简道云账号与下述平台进行集成绑定，使成员可以在第三方平台中直接使用简道云：

微信服务号集成
钉钉集成
企业微信集成
飞书集成
2. 账号打通

单点登录 功能可将简道云集成至其他系统，打通登录系统、消息通知及通讯录体系，实现统一账号体系和身份认证。在多个应用系统中，用户只需登录一次就可以访问所有相互信任的应用系统。支持以下 3 种配置方式：

配置方式

 | 说明

 |
SAML2.0

 | 安全断言标记语言，使用统一的身份提供服务（IDP）验证用户身份，然后将认证后的安全断言和用户信息返回给简道云，实现账号关联

 |
自定义接口

 | 简化的 SAML 协议，企业客户可在现有 SSO 接口基础上进行修改，按照简道云的要求调用服务和返回参数，并将认证后的用户信息返回给简道云，完成账号关联

 |
CAS

 | 中央身份验证服务，它允许用户在向中央 CAS 服务器提供一次登录凭据（如用户名和密码）后，便可访问所有配置了 CAS 的应用程序，包括简道云

 |
3. 数据对接

通过简道云 API 及 Webhook 功能，企业可以实现与其他外部系统的对接，打通两者间的数据和业务。

API： 提供应用、表单、数据、文件、工作流、通讯录及 CRM 接口。
Webhook：是简道云提供的一种回调机制，可实现当简道云中有数据提交/修改/删除/恢复/表单结构变化时，向外部服务器推送相应的数据/信息。

## 简道云开发模式介绍

- 官方文档：https://hc.jiandaoyun.com/doc/21339

1. 简介

本文将介绍，企业在利用简道云平台进行数字化转型时的三种主要开发模式，帮助企业按需选用。

2. 实施开发模式

2.1 简介

实施开发是简道云提供的一项定制实施服务，配备专业实施顾问团队，能够依据企业需求量身定制业务系统，并迅速开发上线至简道云平台。帮助企业轻松、高效地进行数字化转型，省时省力。

2.2 优势

简道云项目实施团队，能够全面覆盖数百种业务场景下的实施业务，凭借丰富的实践经验，深入洞察并精准把握企业的业务需求和目标，精心打造贴合实际的管理应用。

具有以下五大独特优势：

快速上线：零编码开发模式极大缩短了系统开发周期，提高了项目效率。
成本效益高：相较于传统开发，定制服务费用更低，能够提供卓越的性价比。
开发风险低：采用模块化设计，有效减少定制过程中的风险，确保项目稳定进行。
灵活定制：支持按需定制和灵活调整，以适应企业变化中的业务需求。
服务专业：配备专业项目经理，提供全方位咨询服务和实施服务。
2.3 开发流程

简道云定制服务流程如下，详情参见：定制服务。

3. IT开发模式

3.1 简介

IT 开发模式是指，企业采用自主研发业务系统的方式，由业务部门提出需求，IT 部门负责开发实现，在简道云中搭建业务系统，最终交付给业务部门使用。

3.2 优势

企业在采用 IT 开发模式时，可以享有以下优势：

灵活可控：企业可以根据自己的节奏进行开发，灵活调整以适应市场变化。
技术整合优化：开发时可以有效利用现有技术资源，确保系统性能和稳定性。
创新竞争力：自主研发可以支撑企业创新和市场竞争，通过技术创新驱动业务增长。
长期维护：IT 团队能够提供长期的技术支持和维护，响应业务变化和迭代需求。
知识积累：企业可以通过自研积累技术经验，培养技术型人才。

4. 全民开发模式

4.1 简介

全民开发模式是指，在一定规则下充分调动组织内各角色共同参与的流程治理方式和应用分层开发方式。核心是在高层和 IT 的引导支持下，让所有业务部门都有动力、有能力在简道云中自主开发应用系统，从而深度融合“业务”与“数字”，实现一切业务数字化，一切数字业务化，以数字驱动业务增长。

4.2 开发方式

全民开发模式中，企业内的应用将根据业务复杂度和适用范围进行分层开发，具体开发方式如下：

 | 开发方式

 |

 | 业务使用 IT 团队认可的零代码工具，在 IT 团队制定的规则下自主搭建

 |
2

 | 满足团队或部门内部数据管理和流程管理的应用

4.3 使用价值

全民开发模式能够最大范围的调动员工参与数字化转型、最大限度地提升企业的运营效率，可从 IT 部门层面、业务部门层面、组织层面分别带来深远价值。

1）IT 部门层面

IT 部门在全民开发模式中，不仅是作为传统的需求响应者，也是业务创新的推动者，帮助业务部门提升数字化能力，实现自我服务。具有如下优势：

帮助减轻需求负担：快速变化的轻量业务需求将由业务自行处理，大幅减轻 IT 负担；
业务协作更密切：易于搭建符合业务需求的应用，对应用的最终价值认可度更高；
迎来转型契机：从被动响应需求转变为业务的赋能者、权限规则的制定者，提升在企业内的地位和话语权。
2）业务部门层面

在分层开发方式下，员工参与应用搭建的同时，还能够实现业务流程的梳理、优化和创新，自下而上的驱动组织进步，充分发挥员工的主观能动性和创造力。具有如下优势：

提高工作效率：自主开发实现业务数字化，流程线上流转，帮助提效；
推动业务创新：能够使用简道云快速落地创新思路，支撑业务的创新和持续改善；
提升业务人员综合能力：同时具备业务能力与数字素养，成为极具竞争力的综合性人才。
3）组织层面

全民开发模式能够全面提升员工的数字化意识和数字化技能。同时，能够有效支撑企业高效创新，助于企业实现全员流程线上化、信息可视化，帮助企业全面获取数据，识别创新机会，并通过简道云快速搭建验证创新思路。
