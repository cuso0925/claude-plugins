## 前端事件

- 官方文档：https://hc.jiandaoyun.com/open/12115

1. 简介

1.1 功能简介

前端事件是一种全新的数据获取的方式，可以在数据填报时，主动调用外部接口，实现接口取数、数据验证、数据分析、触发事件等一系列的操作。

前端事件功能所有版本皆可免费使用，无需开通简道云 API 接口，且无需编程即可完成前端事件的配置。如果企业具有开发能力，也可以自己封装接口，来实现想要的数据交互效果！

1.2 应用场景

前端事件可以应用于数据处理、数据验证、数据获取，以及其他自定义的场景等。如：

发票管理场景中，通过上传的发票图片，自动识别发票代码、发票号码等信息，完成增值税发票的识别；
物流管理场景中，通过物流单号查询物流途径点、配送人、配送人电话等物流信息；
活动报名场景中，通过手机验证码来校验手机号的真实性。

2. 设置步骤

2.1 设置入口

1）在「表单设计 >> 表单属性 >> 前端事件」处点击「设置」，进入前段事件的设置页面：

2）进入前端事件设置页面，点击左上角的「添加前端事件」即可添加一个新的前端事件。

注：一个表单最多可设置 100 个前端事件。

2.2 设置名称信息

添加好前端事件后，首先设置前端事件的名称和说明，以便于区分不同的前端事件。设置完成后，点击「下一步」。

注：

1）事件名称即前端事件的命名，必填。

2）事件说明即前端事件的描述信息，非必填。

2.3 设置触发动作

触发动作即触发前端事件的条件。选择触发字段后，当触发字段的值被手动修改时，会触发执行动作：

注：触发动作支持选择的字段包括单行文本、多行文本、数字、日期时间、单选按钮组、复选框组、下拉框、下拉复选框、定位、图片、附件、手写签名、成员单选、成员多选、部门单选、部门多选、子表单子字段。

2.4 执行动作

执行动作是指当发生触发动作时，前端事件将调用接口，完成相应的执行操作。执行动作支持设置为 自定义请求 、选择数据填充 或 调用插件。

3. 保存与调试

1）配置好前端事件的参数后，点击「保存并调试」进入调试页面。

2）进入调试页面后，在触发字段中输入内容，点击「发送请求」，右侧调试信息中将显示请求内容和返回内容，并将返回内容按照返回值设置填写进表单字段中：

4. 注意事项

4.1 请求超时

在执行前端事件的自定义请求时，如发生请求超时，系统将自动进行重试。每次请求时长 15 秒，最多重试三次。若第三次仍超时，则不再继续请求。

而在前端事件执行插件时，插件执行超时时间为 60 秒，且不会自动重试。

4.2 重复赋值

在多个前端事件回填同一字段时，注意排查触发逻辑，避免同时触发多个前端事件导致最终回填的字段值无法控制。

## JsonPath规则详解

- 官方文档：https://hc.jiandaoyun.com/open/12209

JSON是一种轻量级的数据交换格式。一个序列化的对象或数组，其中对象由键和键值组成，键值可以是对象、数组、数字、字符串或者 (false、null、true)中的一个。

对象的构成：{ 键: 键值 }

{“hello”:123} 在这个对象中，键为字符串 “hello”，键值为数字 123；

{“hello”:null} 在这个对象中，键为字符串 “hello”，键值为 null。

数组的构成：[   数组 或 对象   ]

[ {“test1”:123} , {“test2”:234} ] 在这个数组中，包含了2个对象。

当然，数组里面也可以同样包含对象或数组，对象里面也可以包含对象或数组。

正常的接口都会给出返回的示例，我们可以在此处看到返回的数据结构：

对于返回的数组，我们需要从中获取我们需要的数据，就需要使用JSON Path规则进行索引。

对于在JSON Path中，$表示根元素，我们根据不同的类型，采用不同的索引方式。

对于对象，我们可以给出键来索引值。

例如：

{“hello”:123}

我们为了获取键值123，可以根据键来索引；

$.hello 或者 $[‘hello’]

注意，如果键为中文，必须采用 $[‘键’] 的形式。

对于数组，我们必须按顺序来索引。

例如 [ {“test1”:123} , {“test2”:234} ] 我们需要索引数组里面第一个对象的值，则 $[0].test1；需要索引数组里面的第二个对象的值， $[1].test2。[0]表示索引数组里面的第一个对象或数组或值，[1]表示索引数组里面的第二个对象或数组或值，以此类推…

前端事件对于子表字段的支持可以分为两种情况：

触发字段为主表字段，返回字段为子表字段
触发字段为子表字段，返回字段也为子表字段
4.1 触发字段为主表字段

触发字段为主表字段，返回值字段为子表字段时，可以接收数组数据，并且自动按数组的行数创建相同行数的子表单。如下图中，可以自动将快递的时间、状态信息（数组）写入子表单中，根据数组的行数自动创建子表单行。

Jsonpath配置方式：使用[*]可以选取不固定长度的数组，数组里面每有一行会自动在子表单创建一行；

例如返回数据为：

            {
                "context": "【江苏省无锡市锡新开发区公司】 已收入",
                "time": "2020-08-19 06:20:16"
            },
            {
                "context": "【无锡转运中心】 已发出 下一站 【江苏省无锡市锡新开发区公司】",
                "time": "2020-08-19 04:16:37"
            }

原先我们获取数组一行的时间的话，需要使用：

$['showapi_res_body']['data'][0]['time']

这里的[0]表示索引数组第一行的数据。而如果我们是要获取数组里面所有的time，根据其行数自动在子表单创建行，则可以写成:

$['showapi_res_body']['data'][*]['time']

前端事件功能所有版本皆可免费使用，无需开通简道云 API 接口，且无需编程即可完成前端事件的配置。如果企业具有开发能力，也可以自己封装接口，来实现想要的数据交互效果！
