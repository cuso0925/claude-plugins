## 一、系统级限制

### 1.1 请求体限制
- 所有请求上限：**2MB**（表单保存、数据提交时常见瓶颈）

### 1.2 系统超量处理
- 缓冲期：人数/数据量超限后 **15天** 缓冲期，消耗完毕后停用
- 子管理员超限：所有子管理员均失效

## 三、表单字段限制

### 3.1 各类字段核心限制

| 字段类型 | 限制 |
|----------|------|
| 计算字段 | 每表单最多 **100个**；单应用最多100个含计算字段的表单；不可互相引用；不可拖入子表单 |
| 关联数据 | 每表单最多 **50个**；不支持CRM预定义表；不可作为子表单字段 |
| 关联子表 | 每表单仅1个启用「随主数据一同新增」；最多新增500条关联数据 |
| 子表单 | LEFT/LOWER等部分函数不能直接在主表使用子表单字段 |
| 选择数据 | 数据工厂输出表不可作为数据源 |
| 查询字段 | 查询数据不入库；必须加过滤条件 |

### 3.2 关联类型字段关键限制（高频出错）

- 单表单内所有计算字段引用关联表总数 ≤ **20张**
- 单计算字段最多选用 **20张** 关联配置聚合变量（每张最多10个）
- 一张表单最多被 **100张** 表单关联
- 一张表单只能构建 **1个** 关联本表
- 关联本表不允许 **自关联**
- 计算字段值的变更 **不触发** 智能助手、智能助手Pro、Webhook
- 计算字段和关联数据之间禁止 **成环设置**

### 3.3 数据联动限制

- 主表字段只能联动主表字段内容
- 子表单整体联动时，多次提交的数据不可被同时联动
- 支持联动图片和附件字段
- 联动表单支持聚合表和数据工厂输出表

## 四、公式跨场景支持矩阵（核心参考）

这是多功能组合方案中最容易出问题的环节——**一个在表单中完美运行的公式，到了数据工厂或仪表盘可能完全不工作**。

| 函数类别 | 表单字段 | 批量修改 | 数据工厂字段设置 | 仪表盘统计表 | 仪表盘明细表 |
|----------|:--:|:--:|:--:|:--:|:--:|
| SUMIF / SUMIFS | ✅ | ❌ | ❌ | ❌ | ❌ |
| COUNT / COUNTIF | ✅ | ✅ | ❌ | ✅ | ❌ |
| LARGE / SMALL | ✅ | ✅ | ❌ | ❌ | ❌ |
| MAPX 系列 | ✅ | ❌ | ❌ | ❌ | ❌ |
| GETUSERNAME | ✅ | ❌ | ❌ | ❌ | ❌ |
| RECNO | ✅ | ❌ | ❌ | ❌ | ❌ |
| TEXTUSER / TEXTDEPT | ✅ | ❌（导出导入不触发） | ❌ | ❌ | ❌ |
| TEXTLOCATION | ✅ | ❌ | ❌ | ❌ | ❌ |
| UUID | ✅ | ✅ | ❌ | ❌ | ❌ |
| ISEMPTY | ✅ | ❌ | 仅文本/日期 | ❌ | ❌ |
| DISTANCE | ✅ | ✅ | ❌ | ❌ | ❌ |
| SPLIT / UNION | ✅ | 受限 | ❌ | ❌ | ❌ |
| RMBCAP | ✅ | ✅ | ❌ | ❌ | ❌ |
| 加减乘除 | ✅ | ✅ | ✅ | ✅ | ✅ |
| SUM / AVG / MIN / MAX | ✅ | ✅ | 部分 | ✅ | ❌ |
| TEXT（日期格式化） | ✅ | ❌ | ❌ | ❌ | ❌ |
| DATE | ✅ | ❌ | ❌ | ❌ | ❌ |

> **日期格式化说明**：`TEXT(DATE(日期字段),'yyyy-MM-dd')` 可将日期转为格式化文本。**注意引号为单引号**。支持的占位符：`yyyy`（年）、`MM`（月，两位）、`dd`（日，两位）、`HH`（时）、`mm`（分）、`ss`（秒）。不支持单数字占位符（如 `M`），因此无法直接输出 `2026-5-29`，只能输出 `2026-05-29`。如需不带前导零，用 `YEAR()&"-"&MONTH()&"-"&DAY()` 拼接。

### 4.1 公式通用限制

- 每个公式最多 **2000行**，单行不超过 **10000字符**
- IFS函数最多 **127个条件**
- 数据工厂计算字段：公式嵌套不超过 **5层**
- 数据工厂不支持数字字段空值判断

### 4.2 常见"不可行"场景速查

| 用户想法 | 不可行原因 |
|----------|-----------|
| "表单用 MAPX 汇总关联数据，然后在数据工厂分析" | MAPX 在数据工厂不支持 |
| "表单用 SUMIF 做条件求和，仪表盘直接展示" | SUMIF 仪表盘不支持，改用聚合表 |
| "在仪表盘统计表里用 SPLIT 解析数据" | SPLIT 仪表盘不支持 |
| "表单计算字段变更触发智能助手" | 计算字段变更不触发智能助手 |
| "数据工厂计算字段用 COUNTIF 统计" | COUNTIF 在数据工厂不支持 |

## 五、数据工厂完整限制

### 5.1 数据流整体

- 最多 **200个** 数据处理节点
- 横向连接、追加合并、分组汇总各最多 **50个**
- 去重节点最多 **10个**
- 超标数据流不可复制

### 5.2 输入节点

- ❌ 聚合表不可作为数据源
- 含多个子表单：每次只能选 **1个** 子表单
- 输入节点不能直接连接输出节点
- 输入节点名称不可更改

### 5.3 输出节点

- 每数据流仅 **1个**
- 输出上限：**100万条** 数据
- 输出数据量不得超过输入的 **2倍**
- 数据工厂处理后的数据 **不能直接导出**，需通过仪表盘间接导出

### 5.4 各处理节点详细限制

| 节点 | 限制 |
|------|------|
| **横向连接** | 单节点最多2张表；不支持连接字段：复选框组、下拉复选框、成员多选、部门多选、子表单、图片、地址；空值不匹配；笛卡尔积超10万条导致更新失败 |
| **追加合并** | 最少2张表，最多10张；仅同类型字段可合并 |
| **行转列** | 最多处理5000条数据；列字段预览上限100项 |
| **分组汇总** | 分组字段：文本/数值/日期/地址/成员/部门；汇总方式依字段类型而异 |
| **字段设置** | 不支持：COUNT、COUNTIF、LARGE、SMALL、SUMPRODUCT、MAPX系列、DISTANCE、UUID；公式嵌套≤5层 |
| **数据筛选** | 支持筛选条件并集/交集；支持不添加条件全部输出 |

## 六、智能助手Pro 完整限制

### 6.1 触发判定表（必须逐条检查）

| 操作 | 触发智能助手Pro？ |

| 表单中删除一条数据（单独勾选） | ✅ |
| 流程节点提交（有数据修改） | ✅ |
| 定时触发 | ✅ |
| 导入数据（Excel/API批量导入） | ❌ |
| 批量修改（单条/多条均不触发） | ❌ |
| 多处删除（勾选多条/筛选删除/全部删除） | ❌ |
| 九数云回填数据 | ❌ |
| 输出表同步数据 | ❌ |
| 修改为原值（非有效修改） | ❌ |
| 删除子表单内容（属于修改动作） | ❌ |
| 计算字段值变更 | ❌ |
| 智能助手之间互触发 | ❌ |
| 流程节点未执行数据修改直接提交 | ❌ |

### 6.2 数量限制

| 操作 | 限制 |
|------|------|
| 删除/查询多条/新增/修改 | 每次最多 **200条** |
| 新增子表单数据 | 每条数据最多 **200条**子数据 |
| 触发链累计新增 | ≤ **1000条** |
| 触发树1小时内新增 | ≤ **10000条** |
| 日期字段触发 | 单次最多 **500条** |
| 修改子表单多数据 | 计算量 ≤ **100万** |

### 6.3 执行时间限制

| 节点类型 | 超时 |
|----------|------|
| 插件节点 | 1分钟 |
| 查询单条/多条节点 | 30秒 |
| 修改数据节点（选表单方式） | 30秒 |
| 删除节点 | 无超时限制 |

### 6.4 不支持操作

- ❌ 不支持删除子表单数据（仅能删除整条数据）
- 条件分支同时执行可能导致冲突，建议串行修改节点

## 七、仪表盘功能限制

- 统计表公式仅支持：SUM、AVERAGE、COUNT、MAX、MIN + 加减乘除
- 明细表公式仅支持：加减乘除
- 删除后30个自然日内可付费恢复
- 2022年5月11日前删除的数据不支持恢复

## 十、功能组合核心判定流程

回答涉及2个及以上功能的方案时，按以下顺序逐项检查：

### 检查清单

**默认企业版**，仅检查平台级限制（非版本限制）：
1. **公式迁移检查** → 公式从表单到数据工厂/仪表盘是否可用？（对照矩阵）
2. **触发链检查** → 方案是否依赖智能助手Pro触发？触发条件是否满足？
3. **成环检查** → 是否存在关联数据→计算字段→智能助手的引用链？
4. **数据源检查** → 数据工厂输入源是否合法？（聚合表不可为输入源）
5. **上限检查** → 数据量和节点数是否接近上限？
6. **导出检查** → 最终数据能否按预期导出？

### 常见组合冲突速查

| 组合方案 | 冲突点 | 替代建议 |
|----------|--------|---------|
| 表单MAPX → 数据工厂分析 | MAPX数据工厂不支持 | 改用聚合表替代MAPX |
| 表单SUMIF → 仪表盘展示 | SUMIF仪表盘不支持 | 用聚合表做条件求和再接入仪表盘 |
| 数据工厂输出 → API导出 | 输出表不能直接导出 | 通过仪表盘中转再导出 |
| Excel导入触发智能助手 | 导入不触发智能助手 | 改为API逐条新增触发 |
| 计算字段 → 智能助手 | 计算字段变更不触发 | 改为关联数据+智能助手，注意成环 |
| 聚合表 → 数据工厂 | 聚合表不可作工厂输入源 | 用原始表单作输入，在数据工厂内聚合 |
